### 📌 Brain Tumor Detection Using Deep Learning

Brain tumors are one of the most critical health concerns, and early detection plays a vital role in treatment and patient survival. Manual detection using MRI scans can be time-consuming and prone to errors, highlighting the need for automated systems to assist medical professionals.

In this project, we present a deep learning-based methodology to detect and classify brain tumors from MRI images into four categories: Glioma, Meningioma, Pituitary Tumor, and No Tumor. Our model leverages convolutional neural networks (CNNs) to extract features from MRI scans and accurately predict tumor type.

### 📂 Project Description

For this project, we have used a well-labeled dataset of brain MRI images categorized into the above four classes. The dataset has been preprocessed and resized to ensure consistent input for the model.

We trained a CNN model using TensorFlow/Keras, and implemented a Flask web application to allow users to upload MRI images and get real-time tumor detection predictions.

### 🧾 Key highlights:

- CNN-based model for brain tumor classification

- User-friendly web interface using Flask

- Handles uploaded images and returns tumor type along with confidence score
### 📊 Dataset

The dataset consists of MRI images of brains categorized into the following classes:

- Glioma

- Meningioma

- Pituitary Tumor
  
- No Tumor
